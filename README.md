# Personal Website

This repository contains the source code for my personal website at **rogerdavila.com**.  
The site is a single-page application built with plain HTML and CSS and is designed to be lightweight, accessible and responsive.  

## Structure

- `index.html` — the main page, containing sections for about, skills, work experience, certifications, portfolio links and contact information.  
- `402ddd13-0ca0-4498-b10c-40bb4e52bced.png` — abstract background image used in the header.  
- `README.md` — this documentation file.  

## Development

The site is built using only **HTML and CSS**, with no external frameworks, in order to keep it simple and fast.  
You can preview it locally by simply opening `index.html` in any browser.  

## Deployment

The recommended approach is to deploy this page through **GitHub Pages** or any static hosting provider.  
To publish with GitHub Pages:

1. Commit and push your changes to the `main` branch.  
2. In repository settings, enable **GitHub Pages** with source = `main` branch.  
3. Your site will be available at: `https://<username>.github.io/personal_site/`.
